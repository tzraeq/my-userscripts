# 个人自用油猴脚本

记录日常使用的网页增强脚本，按需添加和维护。

## 脚本目录

| 脚本 | 适用网站 | 功能 |
| --- | --- | --- |
| [wzyp 店铺增强](./wzyp-shop-enhancer.user.js) | `wzyp.cn/shop/*` | 默认隐藏缺货、价格排序、回车搜索 |

## 安装

1. 在浏览器安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/) 扩展。
2. 从上方目录打开需要的 `.user.js` 文件，复制全部内容。
3. 打开扩展管理面板，选择“添加新脚本”，用复制的内容替换默认模板并保存。
4. 如果扩展提示需要启用“允许用户脚本”或开发者模式，按扩展提示开启。
5. 打开或刷新对应网站，确认脚本已启用。

更新脚本时，用最新文件内容替换扩展中对应脚本的内容并保存，再刷新网页。

## 脚本说明

### wzyp 店铺增强

文件：[wzyp-shop-enhancer.user.js](./wzyp-shop-enhancer.user.js)

示例店铺：<https://wzyp.cn/shop/mengze>

列表示例：<https://wzyp.cn/shop/K1PKHQ1F>

- 商品列表上方增加“显示缺货商品”，默认不勾选。
- 自动识别卡片和列表两种商品布局，保留各自的展示方式。
- 支持默认排序、价格从低到高、价格从高到低；按商品当前显示的售价比较，免费商品按 0 元处理。
- 在原站“搜索商品”输入框中按回车即可搜索；中文输入法确认候选词时不会误触发。
- 切换分类、搜索、加载更多后自动重新筛选和排序；隐藏缺货后列表自动补齐空位。
- 筛选、排序作用于当前分类或搜索结果中**已经加载的商品**。需要比较更多商品时，继续点击原站“加载更多”。不会主动下载全店商品。
- 设置在当前页面内保留，刷新后恢复“隐藏缺货、默认排序”。

适配依据为 2026-11-08 的店铺页面结构。网站更换商品卡片或搜索框结构后可能需要更新选择器。

## 新增脚本约定

- 每个脚本使用独立的 `.user.js` 文件，文件名简洁描述适用网站和用途。
- 在脚本头部写明名称、版本、功能和适用页面，`@match` 只匹配需要增强的页面。
- 新增脚本时同步更新上方目录；有配置项或使用限制时，在“脚本说明”中补充。
- 脚本按个人使用需求维护，网站页面改动后按需适配。
